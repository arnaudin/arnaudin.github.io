{% comment %} The 404 page: a map with one tile missing. A real satellite scene of Barcelona is cut into a 5 x 3 grid of simulated tiles. They start as a coarse overview, the way a map shows a lower zoom level while it waits, and resolve pixel by pixel as the full image arrives. One tile never loads: its coarse overview breaks up to leave a "content not found" message. After that the map stays live. javascript/404.js keeps a few tiles at a time dropping back to coarse and resolving again, and every so often the missing tile retries the same way and fails again. The timings are in that file. Which tile is missing is picked at random on each load by 404.js. The markup below puts it in the middle, which is what a visitor without JS gets. Imagery: SpaceEye-T VVHR EO Open Data, scene ST1_202507170959005, from https://registry.opendata.aws/st-open-data. The credit line in the caption is the wording that registry page asks for on derivative data; keep it with the image. The crop is the full-resolution product (0.25 m, 38516 x 41260, 16-bit RGBN GeoTIFF) at offset 4815,15308, size 29150 x 17490, the same area as offset 128,407 and size 775 x 465 in the 1024 px preview. Bands R, G and B were area-downsampled to 1100 x 660 (2x the largest display size), tone-matched per channel to the preview, graded with ffmpeg eq=gamma=1.14:saturation=0.88:contrast=1.03, pulled back per channel to the preview's broad contrast (about x0.84 around the mean), and encoded with cwebp -m 6 -size 195000 (about 190 KB). --nf-lqip below is the same graded crop at 80 x 48, cwebp -q 45. Inline images on .nf-map, all tiny: --nf-lqip the same crop at 80 x 48, so each tile shows 16 x 16 coarse pixels --nf-m1 to --nf-m3 1-bit masks, 64 x 16: four 16 x 16 random patterns side by side (a tile uses one, by --v), about 30%, 58% and 85% opaque. One mask pixel covers one coarse pixel, so stepping through them swaps coarse pixels for sharp ones a scatter at a time. The tile ID is a real zoom-14 address in central Barcelona; 404.js offsets it by the missing tile's column and row.
